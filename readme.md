# 🎓 Premium Teachers' Day Tribute Website

A luxurious, interactive, single-page web application built with HTML, CSS, and vanilla JavaScript to celebrate and express gratitude to teachers. Designed with a **White & Gold Premium** aesthetic, smooth entrance animations, interactive micro-interactions, and direct email integration.

---

## ✨ Features

- **🏆 White & Gold Premium UI:** Crisp, modern aesthetic featuring metallic gold gradients (`#D4AF37`), glassmorphism navigation, and custom interactive cursor tracking.
- **📜 Smooth Scroll & Progress Bar:** Sticky navigation bar with smooth anchor links and a real-time top reading progress indicator.
- **✨ Micro-Interactions & Animations:** Powered by `ScrollReveal.js` for staggered scroll entrances, cursor outline scaling, and 2D header parallax tracking.
- **🎊 Celebration Confetti:** Instant confetti bursts powered by `canvas-confetti` on page load and button clicks.
- **🃏 3D Secret Message Flip Card:** Hoverable card revealing hidden messages with 3D CSS perspective transforms.
- **📧 Direct Email Integration:** Integrated with **EmailJS** to send feedback or compliments directly to your personal email inbox without needing a custom backend server.
- **💡 Daily Thought Generator:** Dynamic JavaScript quote section featuring inspiring educational and technical quotes.

---

## 🛠️ Built With

- **HTML5** & **CSS3** (Custom Properties, Flexbox, CSS Grid, CSS Animations)
- **Vanilla JavaScript** (DOM Manipulation, Event Listeners)
- **Libraries:**
  - [ScrollReveal.js](https://scrollrevealjs.org/) - Scroll entrance reveal animations.
  - [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti) - Confetti particle celebrations.
  - [EmailJS SDK](https://www.emailjs.com/) - Serverless form submissions straight to Gmail.
